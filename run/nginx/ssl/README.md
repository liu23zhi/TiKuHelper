# 证书目录

此目录只读挂载到 `/etc/nginx/ssl`，网关会递归扫描普通文件，文件名和扩展名不影响识别，也不会跟随符号链接。支持 PEM、DER 编码的 X.509 证书、RSA PKCS#1、PKCS#8、EC SEC1 私钥，以及 PKCS#12/PFX 文件。证书和私钥可以分文件或放在同一个文件中。

加密的 PKCS#8、传统加密 PEM 和 PFX/PKCS#12 使用系统设置中的“证书密码候选”逐个尝试。密码候选保存在数据库中，管理页只显示数量和更新时间；不要把密码写入此目录、文件名或日志。未知编码、密码不匹配和损坏文件只会记录诊断，不会阻塞其它证书。

扫描有固定预算：单个文件最多 16 MiB，单次扫描最多读取 64 MiB，最多处理 256 个普通文件。超过预算的文件会被跳过并记录原因；请不要把备份包、日志或其它大文件放入此目录。

证书必须包含有效 DNS SAN，不能只设置 CN。按公钥匹配私钥并检查时间与服务端用途，链中间证书会原样保留。SAN 精确主机优先；`*.a.com` 只对应一层子域。重复 SAN 选择生效较新、到期较晚的证书，最后按内容摘要稳定排序。

可继续使用 `fullchain.pem` + `privkey.key`：只有内容验证与密钥配对都通过时，它们才优先充当默认回退证书；否则按相对路径和内容摘要选择其他有效对。未知 SNI 使用回退证书，客户端仍需正常验证域名与信任链。

网关每 3 秒扫描，同时复核时间有效性。候选证书复制到容器私有目录，密钥权限 0600，完整配置 `nginx -t` 通过并确认 reload 后切换。坏文件、错配密钥和 reload 失败不会覆盖旧快照；仍有效的旧证书可继续提供 TLS。全部过期后只保留 HTTP；新有效证书到位后自动恢复 HTTPS。

首次为空时不监听 9043，8060/8680 正常工作。健康输出会分别显示 HTTP 与 TLS 状态。证书覆盖的 SAN 不会自动加入“脚本可用域名”；脚本域名和禁止规则仍由管理界面维护。
