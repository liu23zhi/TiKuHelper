# 可信代理列表（tiku-adapter 启动时自动读取工作目录下的本文件）。
#
# 本文件留空、或只有注释 = 信任所有来源的 X-Forwarded-For / X-Real-IP
# （反向代理部署可直接拿到真实客户端 IP）。
#
# 一旦这里（或环境变量 TRUSTED_PROXIES）填了内容，就只有列表内的来源
# 可以使用转发头；其他来源一律回退到直连地址。
#
# 支持的写法（可混用，下面的例子都注释掉了）：
#   172.26.0.3                 一行一个
#   172.26.0.3, 172.18.0.0/16  逗号或分号分隔
#   - 172.26.0.3               YAML 列表项
#   ["172.26.0.3"]             JSON 数组
#   trusted_proxies: 10.0.0.1  键值写法（键名会被自动剥掉）
#   set_real_ip_from 10.0.0.1; nginx real_ip / allow 指令可直接粘贴
#   172.26.0.3 反向代理容器    条目后面的文字当作说明，会被忽略
#   10.0.0.0/255.0.0.0         掩码写法，自动换算成 /8
#   172.26.0.0-172.26.255.255  区间写法，自动换算成最小 CIDR 集合
#   *  /  any  /  all          显式信任所有来源
#   # 注释、// 注释、CRLF、UTF-8 BOM 都会被忽略
#
# 例：
#   172.26.0.3        # 反向代理容器
#   172.26.0.0/16     # 整个 docker 网段
#   127.0.0.1
